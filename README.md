# Snake Game

A modern, stylish Snake game available in two versions:

## Desktop Version (Python/Pygame)

A full-featured desktop Snake game with:
- Particle effects when eating food
- Pause functionality (P key)
- High score persistence
- Dark theme with neon accents
- Snake eyes that follow direction

### Requirements
```bash
pip install pygame
```

### Run
```bash
python snake.py
```

### Controls
- Arrow Keys or WASD: Move
- P: Pause/Resume
- SPACE: Restart (after game over)
- ESC: Quit

---

## Web Version (HTML/CSS/JS)

A responsive browser-based Snake game with:
- Mobile touch controls (swipe + D-pad buttons)
- Particle effects
- Pause functionality
- High score saved to localStorage
- Dark theme with neon accents
- Responsive design

### Run
Simply open `index.html` in any modern web browser.

### Controls
- Arrow Keys or WASD: Move
- P: Pause/Resume
- SPACE or Tap: Restart (after game over)
- Mobile: Swipe or use D-pad buttons
